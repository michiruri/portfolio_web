================================================================================
DEVELOPER MODE GIFS FOLDER
================================================================================

This directory contains the GIFs played on the back of the Contact Section
profile card ("Actual Developer Mode").

HOW IT WORKS:
1. When the card is flipped, the GIFs play in incremental numerical order.
2. The system automatically measures each GIF's animation length and switches
   to the next GIF as soon as the current GIF's loop finishes!
3. After reaching the last GIF, it smoothly loops back to the 1st GIF.

NAMING CONVENTIONS:
Place your GIF files directly in this folder using incremental numbers:
- 1.gif (starts here)
- 2.gif
- 3.gif
- 4.gif
...and so on!

Alternatively, the following naming formats are also supported:
- dev-1.gif, dev-2.gif, dev-3.gif...
- 01.gif, 02.gif, 03.gif...

HOW TO ADD NEW GIFS:
1. Drop your new GIF here.
2. Name it with the next sequential number (e.g., 2.gif, 3.gif).
3. The system automatically discovers and integrates it into the rotation stack!
