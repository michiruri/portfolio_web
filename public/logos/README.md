# Logo Assets

Place the following image files in this directory to display institutional logos on the portfolio:

| Filename           | Used For                                    | Recommended Size |
|--------------------|---------------------------------------------|------------------|
| `psu-logo.png`     | Pangasinan State University (Education card) | 112×112px or larger |
| `panelco-logo.png` | PANELCO III (Experience card)               | 112×112px or larger |
| `topcit-logo.png`  | TOPCIT Certification (Achievements card)    | 112×112px or larger |
| `csc-logo.png`     | Civil Service Commission (Achievements card) | 112×112px or larger |

> All images are displayed at 56×56px (`object-contain`) with a graceful text fallback when missing.
