## Design Context

### Users
Recruiters, hiring managers, and other developers looking at a portfolio. They want to quickly see technical skills, experience, and aesthetic taste.

### Brand Personality
Avant-garde, ultra-premium, distinctive, bold. Not another generic Tailwind template. 

### Aesthetic Direction
- Brutalist or highly customized modern layouts.
- Unconventional typography scaling (massive text mixing with micro text).
- Avoid standard rounded-box dashboard looks.
- High contrast, dark mode.
- Unexpected, delightful interactions.

### Design Principles
1. **Never Default**: Never use standard template layouts (e.g. standard 3-column footer, basic generic cards).
2. **Extreme Contrast**: Mix massive, oversized typography with extremely small, tracked-out microcopy.
3. **Immersive Elements**: Break the grid. Use full-screen overlays instead of side-drawers. Use asymmetrical layouts.
4. **Precision Alignment**: Center things mathematically. Remove random margins/paddings that throw off optical balance.
